# Security Policy / 安全策略

## Supported version / 支持版本

Security fixes are applied to the latest version on the `main` branch.<br />
安全修复会应用到 `main` 分支的最新版本。

## Reporting a vulnerability / 报告漏洞

Do **not** open a public issue for a suspected vulnerability. Instead, contact the repository owner privately through GitHub and include:

- a concise description;
- affected files or behavior;
- reproduction steps; and
- impact and suggested mitigation, if known.

请**不要**通过公开 Issue 报告疑似漏洞。请通过 GitHub 私下联系仓库维护者，并提供：简要说明、受影响文件或行为、复现步骤，以及已知影响和建议缓解措施。

This project creates persistent Codex tasks. Reports involving confirmation bypasses, unsafe path handling, unintended task creation, or privilege escalation are especially important.<br />
本项目会创建持久化 Codex 任务。涉及确认绕过、不安全路径、非预期任务创建或权限提升的问题尤其重要。
